### Day 1: Working with Variables in Python to Manage Data
#### 1- Input/Print
```python
print("Hello")
number = input("Number:")
print("Code: \"xxx\" is successfully")
print("Hello" + " " + "world!")
```

* **`len()`:** Girilen string ifadenin size bilgisini döndürür.
```python
print(len(input("len:")))
```
#### 2- Variables
```python
x = str(3)    # x string '3'
y = int(3)    # y sayı 3
z = float(3)  # z kesirli sayı 3.0
```
* **`type()`:** Değişkenin tipini döndürür.
```python
x = 5
y = "Type"
print(type(x)) #<class 'int'>
print(type(y)) #<class 'str'>
```

### Day 2: Understanding Data Types and How to Manipulate Strings
#### 1- Data Types
* **String** $\rightarrow$ `print("Hello" + "World")` $\rightarrow$ *Hello World*
* **Integer** $\rightarrow$ `print(2+3)` $\rightarrow$ *5*
* **Big Integer** $\rightarrow$ `123_456_789`
* **Float** $\rightarrow$ `3.14`
* **Boolean** $\rightarrow$ `True`, `False`

#### 2- Type Conversions & Functions
* **`type(number)`:** `number` değişkeninin türünü döndürür.
* **`str(number)`:** `number` değişkenini stringe dönüştürür.
* **`float(123)`:** Tam sayıyı ondalıklı sayıya dönüştürür.
