## 2- Data Types

* **String** $\rightarrow$ `print("Hello" + "World")` $\rightarrow$ *Hello World*
* **Integer** $\rightarrow$ `print(2+3)` $\rightarrow$ *5*
* **Big Integer** $\rightarrow$ `123_456_789`
* **Float** $\rightarrow$ `3.14`
* **Boolean** $\rightarrow$ `True`, `False`

### Type Conversions & Functions
* **`type(number)`:** `number` değişkeninin türünü döndürür.
* **`str(number)`:** `number` değişkenini stringe dönüştürür.
* **`float(123)`:** Tam sayıyı ondalıklı sayıya dönüştürür.
